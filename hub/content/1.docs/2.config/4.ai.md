## AI 功能

FlecBlog 已集成 AI 能力，支持在管理端自动生成文章摘要、优化标题。功能基于 OpenAI 兼容接口实现，可连接任意符合该协议的服务或自建模型。

| 功能                       | 输出要求             | 使用位置/场景                      |
| -------------------------- | -------------------- | ---------------------------------- |
| 生成摘要（创作者角度）     | 50-100 字            | 文章编辑页面 - 文章设置 - 文章摘要 |
| 生成 AI 总结（旁观者角度） | 150-200 字           | 文章编辑页面 - 文章设置 - AI 总结  |
| 生成标题建议               | 1 个标题（15-25 字） | 文章编辑页面 - 标题栏              |

### 配置步骤

**API 端点**

即 `Base URL`，AI 服务地址，需以 `/v1` 结尾（如 `https://api.openai.com/v1`）

**API 密钥**

即 `API Key`，避免公开分享

**模型名称**

即 `Model`，用于生成响应的模型 ID

> 不填写模型名称时，将使用 FlecBlog 内置的 AI 代理服务（由 Panel 自动选择可用模型）。若配置了自定义 AI 服务，填写对应模型名称即可覆盖内置服务。

**测试连接**

点击测试连接按钮，会对当前配置进行检测，实质是向该模型发送一条消息，内容是 "hi"，测试速度取决于当前配置模型的响应速度。

**文章摘要提示词/AI 总结提示词/标题提示词**

不同场景下的 AI 生成系统提示词

> **注意事项**
>
> 1. 模型访问速度取决于服务器所在位置，与用户网络位置无关
> 2. AI 接口暂无限流，请在服务商侧设置配额，避免费用失控

## MCP 协议

FlecBlog 已集成 MCP 协议，提供细粒度的文章管理工具，可以在任意支持 MCP 的客户端进行使用。

### 配置步骤

首先复制获取一个 MCP Secret，然后配置客户端。

这里以 Claude Code 和 Cherry Studio 为例：

**1. Claude Code**

打开 `%USERPROFILE%/.claude.json` 文件，找到 mcpServers 并添加以下内容：

```json
"mcpServers": {
  "flecblog": {
    "type": "http",
    "url": "https://后端地址/mcp",
    "headers": {
      "Authorization": "Bearer <secret>"
    }
  }
}
```

**2. Cherry Studio**

打开设置，在 MCP 服务器配置里添加，名称自定义，类型选择 **可流式传输的HTTP**，URL填写 `https://后端地址/mcp`，请求头填写 `Authorization=Bearer <secret>`。

### 注意事项

目前内置了六个工具，全部用于文章管理。查询类工具可访问全部文章，新增、更新与删除只作用于草稿文章，发布状态需在管理后台控制。

### 工具一览

细粒度工具，每个操作独立注册，AI 可按语义直接调用。

| 工具名           | 说明                                                   |
| ---------------- | ------------------------------------------------------ |
| `article_list`   | 分页列出全部文章，返回标题与发布状态，可按发布状态筛选 |
| `article_search` | 按关键词搜索全部文章标题与正文，返回标题与发布状态     |
| `article_get`    | 按 ID 获取文章标题与正文                               |
| `article_create` | 新建文章，只需提供标题与正文，创建后为草稿             |
| `article_update` | 更新草稿文章的标题或正文，省略的字段保持原值           |
| `article_delete` | 删除草稿文章，永久删除不可恢复，已发布文章不可删除     |
